Computer Hardware & CPU Architecture

The System Unit & Motherboard

System Unit: The main case that houses the internal components.

Motherboard: The main circuit board. It acts as the "highway," connecting the CPU, RAM, and all other peripherals via System Buses.

1. The Central Processing Unit (CPU)

The "Brain" of the computer. Its performance is measured by:

  • Clock Speed: Measured in Hertz (Hz). The number of cycles performed per second.
  • Cores: Multiple processors on one chip. More cores = better multi-tasking.
  • Word Length: The number of bits a CPU can process at once (e.g., 64-bit). Higher word length means more data processed per cycle.

Internal Components & Registers

Component Function
Control Unit (CU) Manages the execution of instructions and coordinates all components.
ALU Arithmetic Logic Unit. Performs calculations and logical comparisons.
Cache Memory Fast, expensive memory inside/near CPU to store frequently used data.

The "Big Four" Special Purpose Registers

  • Program Counter (PC): Holds the address of the next instruction to be fetched.
  • MAR (Memory Address Register): Holds the memory address currently being accessed.
  • MDR (Memory Data Register): Holds the actual data/instruction being transferred to/from memory.
  • Accumulator: Stores intermediate results from ALU operations.

2. System Buses (Data Highways)

Buses are paths that allow data to travel between the CPU and other components.

Bus Name Direction Purpose
Address Bus Unidirectional (CPU to RAM) Specifies the location (address) of data to be read or written.
Data Bus Bidirectional Carries the actual data or instructions between CPU and memory.
Control Bus Bidirectional Sends command signals (Read, Write, Reset) and timing pulses.

3. The Machine Cycle (Steps)

  1. Fetch: The address in the PC moves to MAR. The instruction at that address is sent via Data Bus to MDR, then to CIR. PC increments.
  2. Decode: The Control Unit interprets the instruction in the CIR.
  3. Execute: The instruction is carried out (often by the ALU).
  4. Store: Results are saved back into a register or memory.

4. Memory & Secondary Storage

Main Memory Comparison

Feature RAM (Random Access Memory) ROM (Read Only Memory)
Volatility Volatile (Lost without power) Non-Volatile (Stays)
Usage Current programs and active data. Startup instructions (BIOS).

Storage Technologies

Storage Type Technology Notes
Hard Disk (HDD) Magnetic Direct access. Cheap but slow. Requires Defragmentation.
SSD / USB Flash Flash (Solid State) Direct access. Very fast and durable. No moving parts.
Optical (CD/DVD) Laser (Optical) Uses "Pits and Lands". Great for mass distribution.
Magnetic Tape Magnetic Sequential Access. Only used for backups.
