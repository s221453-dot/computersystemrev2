Part 3: Software Systems & Advanced Processing

1. Categories of Application Software

In DSE, you must categorize applications based on their intended use:

Category Description Examples
Productivity Tools used to create documents, spreadsheets, and presentations. Focuses on efficiency in office/school tasks. MS Word, Excel, PowerPoint, Google Sheets.
Communication Facilitates the exchange of information between users over a network. Email clients (Outlook), VoIP (Zoom, WhatsApp), Web Browsers.
Media Development Used to create or edit digital content like images, videos, and audio. Adobe Photoshop, Premiere Pro, Audacity.
Educational Software designed specifically for teaching, learning, or self-assessment. LMS (Moodle, Google Classroom), Duolingo, Math simulations.

2. Processing Modes & Methods

A. Batch Processing

Data is collected over a period and processed all at once without user intervention.

  • Characteristics: High volume, processed during "off-peak" hours (e.g., midnight).
  • DSE Example: Generating monthly bank statements, processing payroll, utility billing (Electricity/Water).

B. Real-time Processing

Data is processed immediately as it is received. The output influences the next input.

  • Characteristics: Requires high-speed response; used when timing is critical for safety or accuracy.
  • DSE Example: Air traffic control, Nuclear power plant monitoring, Online flight booking (to prevent double-booking).

C. Parallel Processing

Tasks are split into sub-tasks and executed simultaneously using multiple CPUs (or cores) within a single computer.

  • Pros: Massive speed increase for complex calculations.
  • Example: Weather forecasting, 3D video rendering.

D. Distributed Processing

A single task is spread across multiple different computers connected via a network.

  • Pros: Fault tolerance (if one PC fails, others continue); uses existing hardware resources.
  • Example: Blockchain (Bitcoin mining), SETI@home, large-scale web searching.

E. Virtualization

Using software to create multiple virtual machines (VMs) on one physical computer. Each VM can run its own Operating System.

  • Pros: Reduces hardware costs, improves resource utilization, easier to test different OS environments.
  • Example: Running Windows on a Mac using Parallels, Cloud servers (AWS/Azure).

3. Operating System Specializations

Types of OS

  • Single-user, Single-tasking: Basic OS like MS-DOS.
  • Multi-tasking: Allows one user to run multiple apps at once (Windows, macOS).
  • Multi-user: Allows multiple users to access the computer's resources simultaneously (Linux servers).

Disk Defragmentation (Deeper Look)

When files are saved, they are often split into "fragments" across the disk. This utility reorganizes them into contiguous sectors.

  • Benefit: Reduces the physical movement of the Read/Write head in an HDD, speeding up the system.
  • Warning: Never defrag an SSD; it doesn't have a physical head and defragging wears out the flash memory cells!
